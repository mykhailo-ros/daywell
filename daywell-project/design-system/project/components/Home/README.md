# Home

The hub screen: greeting, one Today list across habits, meditation and exercise with one-tap check-in rings, a progress strip and three section entry points.

- Consumer provides: today's items in time order (type, title, meta, done state), the longest active streak, today's done/total and the latest badge.
- A check-in here updates the same item in its own section.
- Do: keep done items in place, greyed to `ink-3`. Don't: count what's left or show warnings.
