Create habit, step 2

First choose the days, then either a time or a routine anchor.

  • Every day fills all seven days. Selected days lets each day be toggled.
  • At a time uses a time picker, and the reminder is on by default at that time.
  • With a routine offers Morning, After lunch, After dinner and Before bed. It still asks for an optional reminder time, which is off unless one is added.
  • The summary line above Save reads the habit back in plain words. Save adds it to My habits and to Today if it's due.
